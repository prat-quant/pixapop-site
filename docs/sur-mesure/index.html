Comment ça se passe

De votre idée à votre site en ligne.

  1. Écouter

    Un premier échange sur votre métier, vos clients et ce que le site doit vous apporter.

  2. Dessiner

    Une première version à regarder sur votre téléphone, pour décider sur du concret.

  3. Construire

    Les pages, les formulaires, les tunnels, les e-mails ; pour une application, la publication sur les stores.

  4. Faire grandir

    Les visites et les demandes mesurées, et Studio pour faire venir du monde.
